# Airea – Landing Page

## Descripción del proyecto

Airea es una propuesta de solución tecnológica orientada a informar y concientizar sobre la calidad del aire en Lima Metropolitana. Su objetivo es ayudar a las personas a comprender las condiciones ambientales y tomar decisiones más informadas antes de realizar actividades al aire libre o desplazarse por la ciudad.

Este repositorio contiene el desarrollo del **Landing Page de Airea**, una interfaz web que presenta la propuesta de valor, las principales características y las vistas de acceso y registro de la plataforma.

## Objetivos

- Presentar la propuesta de valor de Airea.
- Comunicar las principales funcionalidades de la solución.
- Brindar información introductoria sobre la calidad del aire y sus indicadores.
- Facilitar la navegación hacia las interfaces de inicio de sesión y registro.
- Ofrecer una interfaz clara, intuitiva y adaptable a distintos dispositivos.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** estilos, diseño visual y adaptación de las interfaces.
- **Google Fonts:** tipografía Inter.
- **Material Symbols:** iconografía utilizada en las interfaces.
- **Git y GitHub:** control de versiones y gestión del código fuente.
- **GitHub Pages:** publicación del Landing Page.

## Requisitos

Para visualizar o ejecutar el proyecto localmente se necesita:

- Un navegador web actualizado.
- Git (opcional, para clonar el repositorio).
- Un editor de código, como Visual Studio Code (opcional).

No se requiere instalar dependencias ni configurar un servidor backend para visualizar las interfaces.

## Instalación y ejecución local

1. Clonar el repositorio:

```bash
git clone https://github.com/AireaLabs/Airea-LandingPage.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Airea-LandingPage
```

3. Abrir el archivo `index.html` en un navegador web.

También se puede abrir la carpeta del proyecto con Visual Studio Code y utilizar una extensión como Live Server para visualizar las páginas durante el desarrollo.

## Consideraciones

- Los valores de calidad del aire y la ubicación mostrados en las vistas de demostración son referenciales y no representan mediciones en tiempo real.
- Las interfaces de inicio de sesión y registro corresponden a vistas demostrativas; no cuentan con un servicio backend de autenticación ni almacenamiento de cuentas.
- El proyecto se centra en la presentación visual y navegación del Landing Page como parte del desarrollo de la solución Airea.
